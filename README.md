

# Lada Schröderová - Portfolio

A responsive portfolio website showcasing my projects, experience, and professional skills.

- [Live Demo](https://ladaschroder.github.io/lada-schroder/)

## About

Welcome to my portfolio! This site is a comprehensive showcase of my work, including internship experiences, projects, and technical proficiencies. The site features a clean, modern design with smooth scrolling and interactive elements.

## Technologies Used

- **HTML5**: Semantic markup and modern web standards
- **CSS3**: Advanced styling with grid layouts, flexbox, and animations
- **JavaScript**: Interactive components and scroll behavior
- **Vite**: Modern build tool and development server
- **React**: Component-based architecture (integrated via Vite)

## Sections

- **Hero Section**: Eye-catching introduction with portrait
- **About/Skills**: Information about my background and expertise
- **Internship Experience**: Detailed showcase of internship projects
- **Work & Projects**: Portfolio of completed projects
- **Skills & Languages**: Technical abilities and language proficiencies
- **Contact**: Easy way to get in touch
